ශ්‍රිත/ප්‍රස්ථාර

  • ශ්‍රිත/ප්‍රස්ථාර කියන්නේ මොනවද?

    යම් දෙයක් (x) වෙනස් වීමට අනුරූපව තවත් දෙයක් (y) වෙනස් වෙන විදිය රූප සටහනකින් පෙන්වන එක තමා අපි ප්‍රස්තාර වලින් කරන්නේ.

  • සරල රේඛීය ප්‍රස්ථාර (y = mx + c)

    උදාහරණය: ටැක්සි ගාස්තුව
    • ටැක්සියට ගොඩවුණු ගමන් අය කරන අනිවාර්ය මුදල = රු. 100 (මේක c)
    • යන හැම කිලෝමීටරයකටම එකතු වන මුදල = රු. 50 (මේක m)
    • ඔයා ගිය මුළු දුර = x

    y = 50x + 100
    මෙහි y කියන්නේ ඔයා ගෙවිය යුතු මුළු ගාස්තුවයි.

  • වර්ගජ ප්‍රස්ථාර (y = ax² + c)

    උදාහරණය: කාමරයකට ටයිල් ඇල්ලීම

    හිතන්න ඔයාගේ ළඟ සමචතුරස්‍රාකාර කාමරයක් තියෙනවා. ඒ කාමරේ පැත්තක දිග x මීටර් කියලා ගමු.

    • කාමරේ වර්ගඵලය = x²
    • එක් වර්ග මීටරයකට යන ටයිල් ප්‍රමාණය = a
    • අමතරව ගෙන එන ටයිල් ප්‍රමාණය = c

    y = ax² + c
    එතකොට කාමරේ පැත්තක දිග අනුව කාමරේට ඕනෑ කරන මුළු ටයිල් ප්‍රමාණය (y) මේකෙන් හොයන්න පුළුවන්.

අපි මේ කතාකරපු m අනුක්‍රමණය ලෙසත් c අණ්තඃඛණ්ඩය ලෙසත් හඳුන්වනවා. පහලින් ඔයාට පුලුවන් අනුක්‍රමණය හා අණ්තඃඛණ්ඩය අනුව ප්‍රස්තාරයක වෙනස් වීම පරීක්ශා කරන්න.
